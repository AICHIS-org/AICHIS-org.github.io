# Security policy

The AICHIS website is a static site (plain HTML, CSS and JavaScript) served
by GitHub Pages. It has no server, no database and no user accounts, and it
does not collect visitor data.

## Reporting a problem

If you find something that could harm visitors or the people listed on the
site — for example a way to inject a script, a link that leads somewhere
malicious, or personal information published by mistake — please tell us
**privately** instead of opening a public issue:

- Use **[Report a vulnerability](https://github.com/AICHIS-org/AICHIS-org.github.io/security/advisories/new)** on GitHub, or
- Email **aichis2022@gmail.com** with "Security" in the subject.

Please include the page or file involved and how to reproduce the problem.
We are a volunteer association, so we aim to reply within a week.

## Removing personal information

If you are listed on the site and want your details changed or removed,
email **aichis2022@gmail.com**. You do not need to give a reason.
